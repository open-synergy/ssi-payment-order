=========================================
Payment Order + Operating Unit
=========================================

Glue module that adds Operating Unit support to the Payment Order module.
Extends ``payment_order``, ``payment_request``, and ``batch_payment_request``
with ``mixin.single_operating_unit``, so payment order documents can be scoped
and restricted per operating unit.


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-payment-order
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Payment Order + Operating Unit*
6.  Install the module
